activity

Show a bar chart of transaction counts per week, or other report
interval.

Flags:
  -O --output-format=FMT    select the output format. Supported formats:
                            txt, svg, html, csv, tsv, json.
  -o --output-file=FILE     write output to FILE. A file extension matching
                            one of the above formats selects that format.
  -w --width=N              with --chart: draw the chart N characters wide
                            (default: the terminal width)
     --txns                 count transactions, showing just the total
                            (default)
     --postings             count postings, showing each account's count
  -S --sort-amount          with --postings, sort accounts by posting count,
                            largest first
  -T --total                show the total count, below the chart
  -A --average              show the average count per period, below the
                            chart (and as a line in SVG charts)

The activity command shows how many transactions there are in each week
(or with a report interval, each day, month, quarter etc.), as a bar
chart. Each transaction is one character, unless there are too many to
fit, when the bars are scaled down. With query arguments, it counts only
the transactions which have at least one matched posting.

Or with --postings, it shows how many postings there are in each period,
with each account's postings stacked in its own colour. With query
arguments, it counts only the matched postings. This is a shortcut for
balance --count --chart, with a weekly interval by default, so it can
show charts in all the same ways: eg with -1 or other depth limit to
show less detail, -0 to show just the total count, without the accounts'
detail, -S/--sort-amount to show the accounts with most postings first.
(Transaction counts show just the total, since a transaction's postings
can be in several accounts.)

--txns selects transaction counts explicitly; if both --txns and
--postings are given, the last one wins.

Both kinds of chart can be shown in the usual ways, eg with -w/--width
to set the width, -T/--total and -A/--average to show the total count
and the average count per period below the chart (in graphical charts,
the average is also drawn as a dashed line), or -o FILE.svg (or -O svg)
for a graphical chart.
