# AI usage reports

Additional notes about the hledger project's AI usage,
complementing the [AI policy](https://hledger.org/AI.html).

Related scripts are in Justfile: run `just ai help` (or `just help` in this directory)

Files in this directory. The parenthesised ones are not committed.

- ccusage.rules            - for reading `ccusage` output to generate ccusage.journal.
- (ccusage.journal)        - a snapshot of local claude code usage (from ccusage).
- (aicommits.csv)          - a snapshot of AI usage data extracted from commits with `aicommits`.
- aicommits.csv.rules      - for reading from aicommits.csv or `aicommits`.
- aicommits-summary.rules  - for reading a monthly summary of the aicommits data.
- ai.journal               - the project's permanent log of estimated AI usage.

### Offset scenarios

Here are some scenarios where hledger development's AI usage is offset by users' AI usage reductions from using hledger.
I think these effects will be real:

- users will sometimes choose hledger instead of AI for a task
- users' AI sessions will sometimes use hledger for a task instead of burning a lot of tokens doing it directly

So providing an efficient tool, even one where AI was used in building it, can bring a net reduction in carbon emissions.
("Let's move the AI use upstream as far as possible - use it briefly at design/implementation time, not repeatedly at usage time.")

For simplicity these assume a constant reduction rate from the start of 2026. In reality the reduction probably starts small and keeps increasing.
